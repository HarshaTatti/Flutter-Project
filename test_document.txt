Privacy-Preserving AI Chatbot - Test Document

This is a simple test document for the Privacy-Preserving AI Chatbot.
You can use this to test the document search functionality on any platform including web browsers.

KEY FEATURES:
The chatbot maintains complete privacy by processing everything locally on your device.
No data is ever sent to external servers or cloud services.
All indexing and search happens right in your browser or on your mobile device.

DOCUMENT SEARCH:
You can load multiple documents and search through them using natural language queries.
The system uses TF-IDF algorithm to find the most relevant passages.
Search results are returned in under 300 milliseconds.

PRIVACY GUARANTEES:
Zero network calls during document processing.
Your files stay on your device permanently.
No third-party access to your personal data.
Complete user control over all information.

TECHNICAL IMPLEMENTATION:
Built with Flutter for cross-platform compatibility.
Uses SharedPreferences for local data storage on mobile.
Uses IndexedDB for local data storage on web browsers.
TF-IDF indexing provides intelligent search capabilities.
